MOOCHAT CONVERSATION TRACKING - INSTALLATION GUIDE
==================================================

Date: February 11, 2026
Version: 1.4

OVERVIEW
--------
This update adds conversation tracking to the MooChat block, allowing teachers to:
- View all student conversations with the AI chatbot
- See message history for each student
- Track when students last used the chatbot

Conversations are stored indefinitely and are only deleted when:
1. The block instance is deleted
2. The course is reset (with the MooChat conversations option checked)

---------------

The following files need to be uploaded to your Moodle server at /var/www/html/blocks/moochat/

INSTALLATION STEPS
------------------

Step 1: Upload Files via gedit
-------------------------------
For each file, use gedit to open the file on your server and paste the contents:

Example:
  gedit /var/www/html/blocks/moochat/version.php
  (paste the new content, save, and close)

Step 2: Update Database
-----------------------
1. Log in to your Moodle site as an administrator
2. Moodle will detect the version change and show an upgrade notification
3. Click "Upgrade Moodle database now"
4. The upgrade script will create the new block_moochat_conversations table
5. Click "Continue" when the upgrade completes

Step 3: Compile JavaScript
--------------------------
Since you're not on the server right now, you'll need to compile the JavaScript later.

When you're back on the server, run:
  cd /var/www/html/blocks/moochat
  grunt amd

OR alternatively, purge all caches from Moodle admin:
  Site administration → Development → Purge all caches

Step 4: Clear Moodle Caches
----------------------------
After uploading all files:
1. Go to Site administration → Development → Purge all caches
2. Click "Purge all caches"

TESTING
-------

Test as a Teacher:
1. Go to a course with a MooChat block
2. Turn editing on
3. You should see two buttons in the block:
   - "Edit Configuration"
   - "View Conversations" (NEW)
4. Click "View Conversations"
5. Initially you'll see "No student conversations yet"

Test as a Student:
1. Log in as a student
2. Have a conversation with the chatbot
3. Send a few messages back and forth

Verify as Teacher:
1. Log back in as a teacher
2. Click "View Conversations" in the block
3. You should see the student listed with message count and timestamp
4. Click "View Details" to see the full conversation
5. You should see the conversation in a chat-style format with timestamps

Test Block Deletion:
1. Delete a MooChat block instance
2. Verify conversations are deleted from the database:
   SELECT * FROM mdl_block_moochat_conversations WHERE instanceid = [deleted_id];
   (should return no results)

Test Course Reset:
1. Go to Course administration → Reset
2. Check "Delete all MooChat conversations"
3. Complete the reset
4. Verify conversations are deleted for all blocks in that course

DATABASE SCHEMA
---------------

New Table: mdl_block_moochat_conversations
- id: Primary key
- instanceid: Which block instance (links to mdl_block_instances)
- userid: Which student (links to mdl_user)
- role: 'user' or 'assistant'
- message: The message text
- timecreated: Timestamp when message was sent

Indexes:
- instanceid-userid (for quick lookup of student conversations)
- timecreated (for sorting by date)

FEATURES ADDED
--------------

1. Conversation Storage
   - Every message exchange is saved to the database
   - Both user and assistant messages are stored
   - Timestamps recorded for each message

2. Teacher View
   - New "View Conversations" button in block (edit mode)
   - List page showing all students with conversations
   - Shows message count and last message time per student
   - Detail page showing full conversation history
   - Chronological display with clear user/assistant labels

3. Data Retention
   - Conversations kept indefinitely
   - Automatically deleted when block is removed
   - Included in course reset process
   - Privacy API compliance (GDPR)

4. Cleanup Mechanisms
   - Block deletion: Removes all conversations for that block
   - Course reset: Option to delete all MooChat conversations
   - instance_delete() method in block class
   - Course reset functions in lib.php

TROUBLESHOOTING
---------------

Issue: "View Conversations" button doesn't appear
Solution: 
- Make sure you're in edit mode (Turn editing on)
- Verify you have block/moochat:configure capability
- Clear all caches

Issue: Conversations not saving
Solution:
- Check JavaScript console for errors
- Verify the external service is registered (check db/services.php)
- Purge all caches
- Make sure JavaScript was compiled with grunt

Issue: Database upgrade didn't run
Solution:
- Check that version.php has version = 2026021100
- Visit yourmoodlesite.com/admin/ to trigger upgrade
- Check PHP error logs for database errors

Issue: "Table doesn't exist" error
Solution:
- Verify the upgrade script ran successfully
- Manually check if table exists:
  SHOW TABLES LIKE 'mdl_block_moochat_conversations';
- If not, the upgrade didn't run - check version number

Issue: JavaScript not working after update
Solution:
- Run: grunt amd (from /var/www/html/blocks/moochat/)
- OR: Purge all caches from Moodle admin
- Check browser console for JavaScript errors
